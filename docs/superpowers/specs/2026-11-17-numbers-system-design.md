# 数值体系总设计（六维 · 境界 · 气血 · 伤害 · 成长预算）

> 用户已拍板的前提：六维上限各 50；"机关"改"体质"，体质 = 气血；境界体质会变，终局东方阳气血 5000+（血牛）；境界只是剧情节点，每章可获得的点数被剧情卡死；任逍遥 9 岁，初始六维合计 35~40，第一章满做约 50；炼体阶段角色强弱：弟子（初期，速度快伤害低）< 马匪（初期偏强，伤害高血厚速度慢）< 任逍遥初始（中期）≈ 紫霞师姐（中期，略强）< 马匪头子（高期）；任逍遥终局极意巅峰（半步半神）仍打不过东方阳（六边形全满，10 个破绽点，半神）。
> 其余全部由我（Claude）决定，目的是**让后续章节不返工**：公式一次写成"带境界参数"的形式，第一章只用最小的一档。

## 1. 设计原则
1. **六维永远只有 0~50 的小数字**，境界不改变六维的含义。
2. **境界通过两个旋钮放大数值**：`伤害倍率 s` 和 `每点体质气血 h`，写在数据表 `data/realms.json`，公式里只读表，不写死。
3. **同境界内的算术和第一章完全一样**（所以第一章调好的手感，到任何境界都成立）。
4. 难度的唯一标尺是 **"敌人招式威胁 vs 玩家反制强度"**，不随 s 放大（反制只看技巧，不看境界）。
5. 每章可得点数由剧情/任务写死，不能刷；支线给的是"分配的选择"和物品，不是无限成长。
6. 剑意（无视防御）是任逍遥的特色：用来对付"境界压制"，不是对付血量。

## 2. 六维（key 与作用）
| key | 名称 | 作用 |
|---|---|---|
| power | 力量 | 出手伤害 = 武学威力 × 熟练度倍率 + 力量（再 × s） |
| speed | 速度 | 出手顺序；反制先手判定（速度 + 武学先手加成 ≥ 对方速度）；反制强度 ±3 修正 |
| defense | 防御 | 受到伤害 = 招式威力 × s_敌 − 防御 × s_我（至少 1） |
| recovery | 恢复 | **每回合结束自动回血 = 恢复 × 2 × s**（玩家与敌人同规则）；吃药回复量 × (1 + 恢复/25) |
| skill | 技巧 | 反制强度 = 技巧 + 武学反制等级 + 速度差修正（−3~+3）；剑意伤害 = (30 + 技巧) × s |
| constitution | 体质 | **气血上限 = 40 + 体质 × h(境界)**；不改变任何其他公式 |

- 原 `mechanism` 全部改名 `constitution`（数据、代码、面板、测试、模拟器）。目前没有存档文件，无需迁移。
- 完美破招规则不变：最强属性 = 武学优势属性（可并列）+ 命中弱点招 + 优势反制。

- 东方阳：六维全 50，半神，气血 = 40 + 50×105 = **5290**；任逍遥终局（极意巅峰，体质约 40）= 40 + 40×90 = **3640**。

## 4. 公式总表（一次写对，第一章 s=1）
- **出手**：伤害 = max(1, floor((武学威力 × 熟练度倍率 + 力量) × s_我) − 防御_敌 × s_敌)；对方晕眩时：伤害 × 1.5，防御按 0。
- **受击**：伤害 = max(1, 招式威力 × s_敌 − 防御_我 × s_我)；反制 ADVANTAGE → 0；BARELY → floor(一半，至少 1)。
- **剑意**：伤害 = floor((30 + 技巧) × s_我)，无视防御，造成不可愈合的伤（wound）。
- **反制**：反制强度 = 技巧 + 反制等级 + clamp(floor((我速 − 敌速)/5), −3, 3)；与招式威胁差 gap：gap < −5 → 不可行；先手且 gap ≥ 0 → 优势；否则勉强。**这部分与境界无关**。
- **回血**：每回合结束 = 恢复 × 2 × s（上限 = 气血上限 − wound）。
- **吃药**：回复量 = 药效 × s × (1 + 恢复/25)，药效写在 items.json（草药 30、更高档药更大），消耗品是"消耗一回合行动"。
- **耐性/晕眩/熟练度** 保持现有规则，熟练度 +4%/级。
- 这些公式放进 `core/damage.gd`、`core/battle.gd`、`core/jianyi.gd`、`core/counter.gd`，**都通过 `core/balance.gd` 里的 `realm(id)` 读表**；`Unit` 增加 `realm` 字段（默认 "lianti"），敌人 def 里可选 `realm`。

## 5. 为什么跨境界仍然成立（压制与终局）
- **境界压制自然出现**：低境界打高境界，(威力×s_低) 不够抵消 防御×s_高，伤害落到 1，也就是"炼体打不动人杰"。**任逍遥的破局手段是剑意（无视防御）和读招**，这正是他的设定。
- **终局例子**（东方阳 s=8，任逍遥 s=6.5，数值举例）：
  - 东方阳一招威力 50，任逍遥防御 40 → 50×8 − 40×6.5 = **140**，任逍遥气血 3640 → 约 26 下。
  - 任逍遥一击（武学 40 + 力量 45）×6.5 − 50×8 = **152**，东方阳 5290 血、恢复 50 → 每回合回 50×2×8 = **800**。**纯硬打是打不动的**（回的比打的多）；必须靠完美破招晕眩（防御归零、×1.5、不回血）、剑意（×6.5 且无视防御）、队友支援。
  - 东方阳 10 个破绽点：连续破招 10 次才晕眩一次，晕眩 2 回合。
- **反制上限**：技巧 50 + 反制等级约 20 + 速度 3 = 73；东方阳招式威胁设 75+，**即使属性练满也无法稳定优势反制**，这就是"属性堆满也打不过"。

## 6. 难度标尺（敌人招式威胁）
以"同阶玩家预期反制强度" P 为基准：
- 杂兵：威胁 = P − 3 ~ P（玩家勉强能优势反制）
- 精英：威胁 = P + 1 ~ P + 4
- Boss：威胁 = P + 4 ~ P + 7（必须靠预判、弱点、剑意）
- 终局：威胁 > 玩家可能的最大反制强度
第一章 P：初始 14（技巧 12 + 反制等级约 2），养成后 19~21。

## 8. 第一章成长预算（卡死）
- 初始 37 + 开局 3 个自由点 = 40；**可选养成总计最多 +10 → 满做 50**。
- 预算分配：宝箱·普通的剑 +2（速 +1 力 +1）；草药任务 +2（恢复 +2）；试招 +2（技巧 +2）；探子 +2（力 +1 防 +1）；**养元丹 ×2（体质 +1/颗，气血 +15/颗）= +2**。合计 10。
- 其余 6 个新支线（砺剑、猎户、河中木匣、发簪、送货、药铺订单）**不给永久属性**：给物品（粗布衣、旧玉佩、草药、铜钱）、熟练度经验；允许其中 1~2 个给**自由属性点 1**，但总量不超 10（实现时在 quests.json 里用"章节预算校验"测试把关）。
- 丹药设定：**养元丹**（体质 +1，永久，每颗按当前境界给气血：炼体 +15，人杰 +30……），不要图标（复用 `icon_item_healing_pills`），只有文字描述。
