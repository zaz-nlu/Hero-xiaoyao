# 武侠古镇 HD-2D 场景素材包 v1

本包包含 **13 张独立生成的场景素材原图**，并提供适合导入游戏工程的常见尺寸与背景处理版本。未包含人物行走图或战斗特效。

## 目录

- `01_textures/256x256/`：4 张 256×256 材质贴图（石板街、灰瓦、旧白墙、深色木板）。
- `01_textures/source_hd/`：同 4 张材质的高分辨率原图。
- `02_building_facades/magenta_1024x768/`：5 张 1024×768 建筑正立面（酒馆、铁匠铺、杂货铺、民居、包子摊），洋红键色背景。
- `02_building_facades/transparent_1024x768/`：同 5 张建筑的自动去背透明 PNG。
- `02_building_facades/source_hd/`：建筑的高分辨率原图。
- `03_props/magenta/`：道具图集、柳树、木船的洋红背景版。
- `03_props/transparent/`：上述 3 张的自动去背透明 PNG。
- `03_props/source_hd/`：对应高分辨率原图。
- `04_backgrounds/`：一张 16:9 古镇街景概念背景。

## 使用提示

1. 贴图的像素尺寸和建筑的 1024×768 尺寸已经输出；若游戏引擎放大，请使用 **Nearest Neighbor / Point** 过滤方式保持像素锐利。
2. `transparent` 文件夹里的去背是基于洋红色自动提取的，柳树细枝、蒸汽等半透明轮廓在正式使用前建议手工检查。
3. 四张材质按照可重复贴图的要求生成，**尚未经过严格无缝接缝验证**。在引擎里做 3×3 平铺测试，若边缘可见，需要进一步无缝修正。
4. 建筑是完整正立面素材，不是已经拆分门、窗、屋檐的模块化瓦片；道具图集亦尚未逐件切分。
5. 原图保留在 `source_hd` 中，可用于后续精修或重新导出。

统一风格：HD-2D 像素画、手绘像素质感、柔和暖光、中国武侠古镇、大地色调、不包含文字与水印。
