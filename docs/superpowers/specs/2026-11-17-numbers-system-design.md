# 数值体系总设计（六维 · 境界 · 气血 · 伤害 · 成长预算）

> 用户已拍板的前提：六维上限各 50；"机关"改"体质"，体质 = 气血；境界体质会变，终局东方阳气血 5000+（血牛）；境界只是剧情节点，每章可获得的点数被剧情卡死；任逍遥 9 岁，初始六维合计 35~40，第一章满做约 50；炼体阶段角色强弱：弟子（初期，速度快伤害低）< 马匪（初期偏强，伤害高血厚速度慢）< 任逍遥初始（中期）≈ 紫霞师姐（中期，略强）< 马匪头子（高期）；任逍遥终局极意巅峰（半步半神）仍打不过东方阳（六边形全满，10 个破绽点，半神）。
> 其余全部由我（Claude）决定，目的是**让后续章节不返工**：公式一次写成"带境界参数"的形式，第一章只用最小的一档。

## 1. 设计原则
1. **六维永远只有 0~50 的小数字**，境界不改变六维的含义。
2. **境界通过两个旋钮放大数值**：`伤害倍率 s` 和 `每点体质气血 h`，写在数据表 `data/realms.json`，公式里只读表，不写死。
3. **同境界内的算术和第一章完全一样**（所以第一章调好的手感，到任何境界都成立）。
4. 难度的唯一标尺是 **"敌人招式威胁 vs 玩家反制强度"**，不随 s 放大（反制只看技巧，不看境界）。
5. 每章可得点数由剧情/任务写死，不能刷；支线给的是"分配的选择"和物品，不是无限成长。
6. 剑意（无视防御）是任逍遥的特色：用来对付"境界压制"，不是对付血量。

## 2. 六维（key 与作用）
| key | 名称 | 作用 |
|---|---|---|
| power | 力量 | 出手伤害 = 武学威力 × 熟练度倍率 + 力量（再 × s） |
| speed | 速度 | 出手顺序；反制先手判定（速度 + 武学先手加成 ≥ 对方速度）；反制强度 ±3 修正 |
| defense | 防御 | 受到伤害 = 招式威力 × s_敌 − 防御 × s_我（至少 1） |
| recovery | 恢复 | **每回合结束自动回血 = 恢复 × 2 × s**（玩家与敌人同规则）；吃药回复量 × (1 + 恢复/25) |
| skill | 技巧 | 反制强度 = 技巧 + 武学反制等级 + 速度差修正（−3~+3）；剑意伤害 = (30 + 技巧) × s |
| constitution | 体质 | **气血上限 = 40 + 体质 × h(境界)**；不改变任何其他公式 |

- 原 `mechanism` 全部改名 `constitution`（数据、代码、面板、测试、模拟器）。目前没有存档文件，无需迁移。
- 完美破招规则不变：最强属性 = 武学优势属性（可并列）+ 命中弱点招 + 优势反制。

## 4. 公式总表（一次写对，第一章 s=1）
- **出手**：伤害 = max(1, floor((武学威力 × 熟练度倍率 + 力量) × s_我) − 防御_敌 × s_敌)；对方晕眩时：伤害 × 1.5，防御按 0。
- **受击**：伤害 = max(1, 招式威力 × s_敌 − 防御_我 × s_我)；反制 ADVANTAGE → 0；BARELY → floor(一半，至少 1)。
- **剑意**：伤害 = floor((30 + 技巧) × s_我)，无视防御，造成不可愈合的伤（wound）。
- **反制**：反制强度 = 技巧 + 反制等级 + clamp(floor((我速 − 敌速)/5), −3, 3)；与招式威胁差 gap：gap < −5 → 不可行；先手且 gap ≥ 0 → 优势；否则勉强。**这部分与境界无关**。
- **回血**：每回合结束 = 恢复 × 2 × s（上限 = 气血上限 − wound）。
- **吃药**：回复量 = 药效 × s × (1 + 恢复/25)，药效写在 items.json（草药 30、更高档药更大），消耗品是"消耗一回合行动"。
- **耐性/晕眩/熟练度** 保持现有规则，熟练度 +4%/级。
- 这些公式放进 `core/damage.gd`、`core/battle.gd`、`core/jianyi.gd`、`core/counter.gd`，**都通过 `core/balance.gd` 里的 `realm(id)` 读表**；`Unit` 增加 `realm` 字段（默认 "lianti"），敌人 def 里可选 `realm`。

## 5. 为什么跨境界仍然成立（压制与终局）
- **境界压制自然出现**：低境界打高境界，(威力×s_低) 不够抵消 防御×s_高，伤害落到 1，也就是"炼体打不动人杰"。**任逍遥的破局手段是剑意（无视防御）和读招**，这正是他的设定。
- **终局例子**（东方阳 s=8，任逍遥 s=6.5，数值举例）：
  - 东方阳一招威力 50，任逍遥防御 40 → 50×8 − 40×6.5 = **140**，任逍遥气血 3640 → 约 26 下。
  - 任逍遥一击（武学 40 + 力量 45）×6.5 − 50×8 = **152**，东方阳 5290 血、恢复 50 → 每回合回 50×2×8 = **800**。**纯硬打是打不动的**（回的比打的多）；必须靠完美破招晕眩（防御归零、×1.5、不回血）、剑意（×6.5 且无视防御）、队友支援。
  - 东方阳 10 个破绽点：连续破招 10 次才晕眩一次，晕眩 2 回合。
- **反制上限**：技巧 50 + 反制等级约 20 + 速度 3 = 73；东方阳招式威胁设 75+，**即使属性练满也无法稳定优势反制**，这就是"属性堆满也打不过"。

## 6. 难度标尺（敌人招式威胁）
以"同阶玩家预期反制强度" P 为基准：
- 杂兵：威胁 = P − 3 ~ P（玩家勉强能优势反制）
- 精英：威胁 = P + 1 ~ P + 4
- Boss：威胁 = P + 4 ~ P + 7（必须靠预判、弱点、剑意）
- 终局：威胁 > 玩家可能的最大反制强度
第一章 P：初始 14（技巧 12 + 反制等级约 2），养成后 19~21。

## 12. 第一章酒馆战调参结论（人工汇总，`tools/tune_tavern.gd` 扫描，human bot，含师姐前戏掉血）

- 结构性发现：**反制只作用于被选中的那个敌人**，其余敌人的攻击全额落在玩家身上；所以"头子 + 5 个马匪"的局面每回合有 6 份伤害，无论单个多低，没准备的玩家 2~5 回合就会被打死。
- 想让没准备"有机会赢"，只能把敌人伤害压到低于玩家每回合回血，结果是打 44 回合的消耗战（胜率对头子伤害极敏感：−4 时 3%，−5 时 72%），体验不佳，**放弃**。
- 采用方案：**没准备 ≈ 必败（0%），准备好 ≈ 80%**。具体：马匪两招威力 +3（乱砍 12、力劈 14），头子数值不变。
  | 配置 | 没准备（初始属性，头子+5 马匪，无草药） | 准备好（养成后，头子+2 马匪，3 草药） |
  |---|---|---|
  | 马匪威力 +0 | 0%（3 回合） | 100%（剩 76 血） |
  | **马匪威力 +3（采用）** | 0%（2 回合） | **80%（剩 37 血）** |
  | 马匪 +3、头子威力 +4 | 0% | 30% |
- 机器人比真人稳，真人的实际胜率会更低；首次在酒馆战败会弹出提示引导去紫霞林。
- 若以后想要"没准备也能险胜"，需要改系统（例如让反制能覆盖多个敌人，或加"退路"），不是调数值能解决的。

## 12. v2（2026-11-20）：境界与六维脱钩，成长换轴

> 用户决定：属性不再和境界挂钩；"修为"只跟剧情走（剧情说突破就突破）；同为天王，勇者之体、魔王之体后期理应比普通天王强；任逍遥长期停在地灵，支线不能没有回报。以下为我的设计，**标「暂定」的数值实现时可调**，其余为已定。

### 12.1 决策摘要
1. **境界 = 剧情触发的"档位"**。它只决定三样东西：伤害倍率 `s`、每点体质气血 `h`、解锁项（内力护体、融合、仙气、领域……）。**不再约束六维合计。**
2. **六维 = 个人成长**。单项上限仍是 50（体质、心法另有超限渠道，见 12.4）；总量由**章节点数预算**控制，不由境界封顶。§3 里的"六维合计参考"改为**NPC 设计参考值**，数据检查里超出时只给**警告**，不报错。
3. **身体天赋**（勇者之体、魔王之体……）决定个体差异：出生值、成长、上限。同档位里"血脉强者"自然更强。
4. **境界压制仍成立**：因为压制来自 `s` 的倍率，不来自六维总和。地灵属性再高，也不会直接超过同属性的天王。
5. 支线奖励的主轴，在地灵这类"属性涨得慢"的阶段，**从属性点换成"容量"和"选项"**（12.5）。

### 12.2 借鉴了什么（只借思路，不照搬）
| 游戏 | 借鉴 | 我们怎么用 |
|---|---|---|
| 《太吾绘卷》《鬼谷八荒》 | 境界是离散档位，功法/心法是横向成长 | 境界只管倍率与解锁，心法、融合、熟练度做横向成长 |
| 《金庸群侠传》 | 丹药、奇遇、秘籍带来永久提升 | 养元丹、回气丹、奇遇；丹药有耐受递减，防止刷 |
| 《八方旅人》 | 职业与技能点是横向成长；支线给装备与技能 | 支线奖励表以装备、技能、融合配方为主 |
| 《女神异闻录》 | 日历、时段、带期限的剧情 | 已采用：四时段、任务交付耗时 |
| 《黑暗之魂》《艾尔登法环》 | 属性有软上限（过阈值收益递减），武器强化是主轴 | 单项 50 以上收益递减；装备品阶做主轴之一 |
| 《火焰纹章》 | 按兵种设属性上限 | **不学**：这正是我们要拆掉的"属性被职业封顶" |
| 《最终幻想战略版》 | 职业熟练度（点数）做横向成长 | 武学熟练度与融合 |

### 12.3 三层成长模型
- **L1 境界档位（剧情给）**：s、h、解锁。表沿用 §3，`六维合计参考` 列改名 `典型合计（仅供参考）`。突破由剧情事件触发，`Progression.on_breakthrough` 已存在，突破时内力回满。
- **L2 个人六维（点数预算给）**：每章固定发点，不能刷。单项 ≤ 50；体质可被心法抬高；装备、丹药可临时/永久加成，总加成封顶 +20（体质 +30）。
- **L3 横向成长轴（支线、探索、心法给）**：内力池上限、紫气池上限、仙气解锁、武学熟练度、心法等级、技能融合、装备品阶、剑意槽、形态覆盖。

战力粗算（只用来调数值，不是实际公式）：`战力 ≈ s × 六维 × (1 + 熟练度加成) + 装备`；气血 = 40 + 体质 × h。

### 12.9 加成桶：地灵期靠支线也能继续变强（用户 2026-11-20 确认方向）
属性不止来自"章节点数"，还有三个**有上限的加成桶**，主要由支线、探索、锻造给，因此地灵期做支线依然有数值回报：

| 桶 | 来源 | 暂定总上限 | 说明 |
|---|---|---:|---|
| 基础点 | 主线节点（12.5.1） | 见预算表 | 不可刷 |
| 修炼加成 | **心法等级、秘籍修炼里程碑**（熟练度到 3/6/9 级各给 +1，加在该流派对应的属性上：剑术偏技巧、速度，拳术偏力量、体质，心法偏体质） | +20（体质桶另有 +10） | 每本秘籍最多给 +3，防止堆书刷点 |

### 12.10 上限提升到 500（用户 2026-11-20 决定，**覆盖 12.4、12.5.1、12.9 里的相关数字**）

**新上限**
- 六维合计软上限 **500**（东方阳，半神）；**单项上限 90**（体质、心法可超限到 100），允许偏科。
- **早期内容的数字不变**：炼体、人杰、地灵阶段的数值（马匪、三火、紫殇等已调好的）原样保留，只在**高处**加长跑道。

### 12.11 修订：魔族大选篇任逍遥"同倍率下近乎无敌"（用户 2026-11-20，**覆盖 12.6 与 12.10 的节奏表**）
**用户的剧情逻辑**：魔王神器把所有人的倍率压到地灵，但**不压属性**；任逍遥在地灵阶段可以靠刷（支线、秘籍、装备）把属性堆到 250~260，而天王级参赛者只有约 220。同倍率下，任逍遥是"六边形战士"，所以他在大选里几乎无敌。这是**剧情层面已经成立的解释**，数值要配合它。

**对设计的修改**
1. **取消"封存修为"**：神器内任逍遥照常成长（取消 12.6 的封存机制），他"能刷"正是大选无敌的原因。
2. **重排任逍遥数值节奏**（暂定，有效值=基础点+满做加成桶）：

| 节点 | 基础点 | 满做有效值 | 境界 |
|---|---:|---:|---|
| 山庄篇 | 128 | 150 | 地灵 |
| 妖族赌局篇 | 170 | 215 | 地灵 |
| 魔族大选篇（神器内，倍率统一） | 205 | 255 | 地灵（被压制） |
| 大选后突破天王 | 250 | 305 | 天王 |
| 精灵之森 | 300 | 360 | 天王 |
| 共和国篇，突破极意 | 350 | 420 | 极意 |
| 终局前 | 390 | 470 | 极意巅峰 |
| 东方阳（对照） | - | 500 | 半神 |

3. **"几乎无敌"要量化**：任逍遥 255 对天王参赛者 220，属性只高约 16%，但"六边形"（没有短板）加上技能、形态覆盖、破招，目标用模拟器验证：对**同档普通参赛者胜率约 85%**，对**精英约 60~70%**，不要变成无脑碾压。
4. **别让这篇变成纯爽**：神器只统一倍率，不抹平**身体天赋和属性**，所以仍然会有压不住的人——魔王之体、勇者之体的继承者，他们的属性高出一大截，可以做大选的最终 Boss；其他参赛者的难度来自**机制**（魔石科技、术法需要"破术"、各族特色），而不是数字。
5. 妖族赌局篇的节奏：任逍遥 215 对极意 220 的贝特，倍率 3.5 对 6.5，**他是被碾压的一方**，靠赌局机制取胜；到了魔族大选篇反过来变成强者，一难一爽，节奏好。

### 12.12 修订：任逍遥的突破时间后移（用户 2026-11-20）
魔族大选篇结束时**突破天王的是厉苍天，不是任逍遥**，因此 12.11 节奏表里"大选后突破天王"一行作废：任逍遥在大选后**仍是地灵**，突破时间待定（建议在精灵之森高潮或共和国篇开头，等用户确认）。其间他的有效值继续按预算成长，地灵高属性（例如 300，倍率 3.5 → 战力约 1050）与普通天王（5.0 × 220 = 1100）相当，不会失衡。厉苍天突破天王时，倍率从 3.5 升到 5.0，队伍战力会有一次明显跳变，数值上需要提前预留。
