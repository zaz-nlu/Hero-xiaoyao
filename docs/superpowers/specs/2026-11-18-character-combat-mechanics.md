# 三位主角战斗机制（底层设计）

状态：用户设计、Claude 整理。**用户已确认**的内容标「定」，我补充的默认值标「暂定」，实现前可调。
关联文档：[数值系统](2026-11-17-numbers-system-design.md) · [战旗战斗设计](2026-11-18-tactics-battle-design.md) · [弱点、破招与招式形态](2026-11-19-counter-and-weakness-design.md)（反制/破招/韧性/融合相关规则以后者为准）

## 0. 设计总则

1. **机制服务人设。** 任逍遥是"解题者"，靠破招；厉苍天走内力，傅剑寒走位移。三人是三种节奏，不靠数值区分。（定）
2. **流派来自加点，不做职业树。** 六维（力量/速度/防御/恢复/技巧/体质）自由分配，资源模型决定"怎么打"，加点决定"强在哪"。（定）
3. **每加一个机制，必须产生一个新的决定。** 只改数字的不加。
4. **分层交付。** 核心层先做并亲手试玩，扩展层、角色层后加（见 §6）。
5. **消耗做成统一接口**，后面角色和面板接入不返工（见 §5）。

## 1. 任逍遥：多面板 + 次数制（定）

任逍遥**没有蓝条**，每个招式有「次数」，**不能靠蓝药回复**。他单人战斗多，需要大量破招，所以不能全带大招，要带很多普通剑术。

战斗中有多个**面板**（驱动方式不同）。第一章只有内力和剑意。

| 面板 | 解锁 | 容量 | 特点 | 恢复 |
|---|---|---|---|---|
| **内力** | 开局 | 每招次数多（普通 5~8，精良 4~5，稀有 3，史诗 2，传说 1；暂定） | 基础面板，伤害正常，承担破招和连击 | 紫气补；战斗后恢复 |
| **紫气** | 紫霞派剧情后 | 4 招，每招 2 次 | 伤害很低，**回血、回内力次数**，是续航面板 | 战斗后恢复 |
| **仙气** | 精灵之森篇 | 暂定 4 招 × 2 次 | 附带元素：冰降速、火持续伤害、水自身回血、雷麻痹 | 战斗后恢复 |
| **剑意** | 开局 | 1 格，随境界增长，最多 4 格，每格只能用 1 次 | 带的是**普通技能**的强化版：伤害最高，**真实伤害无视防御** | **只能靠戳破弱点恢复** |

### 1.1 节奏
内力出招 → 紫气续航 → 剑意收尾 → 靠破招把剑意找回来再打。每场战斗的核心问题是"怎么在次数用完前解决对手"。

### 1.2 剑意（定 + 暂定）
- 剑意格带的是已学的普通剑术，使用时是强化版。（定）
- 格数：炼体 1、人杰 2、地灵 3、天王及以上 4。（暂定）
- 伤害倍率：基础 ×1.5，随六维后期 ×2~3。暂定 `倍率 = 1.5 + 技巧/50 × 1.5`（技巧 50 时 ×3）。
- 真实伤害：无视防御，不受防御系数影响。
- 平衡约束：**4 发剑意约占 Boss 血量的 35%~45%**，不能靠剑意单独打穿，需用模拟器验证。
- 恢复条件（暂定，两种都算）：
  - **破招**：反击打中敌人招式的弱点（现有完美破招）。
  - **破防**：把敌人韧性点打光、使其失衡。
  - 每次恢复 1 格。
- 与现有代码关系：`core/jianyi.gd` 已是"点数有限的一击、破招恢复"，改造为"强化普通技能"即可。

### 1.3 紫气恢复（暂定）
每次使用回 **2 点**内力次数，由玩家选回给哪一招，同时回少量血。每场最多 8 次 → 最多补 16 次内力。

### 1.4 内力面板格数（暂定）
6 格起步，随境界增长。大招（1 次）与普通招要权衡。

### 1.5 兜底与连战（暂定）
- 保留一个**无限次的最弱平 A**，防止次数耗尽卡死，伤害很低。
- 每场战斗开始所有面板满；**连战（一穿七）和精英关中途不恢复**。

### 1.6 仙气元素与限制（暂定）
- 冰：降低目标速度（直接减小其 CT 速度）。
- 火：持续伤害。
- 水：自身回血。
- 雷：麻痹，使目标跳过一次行动。
- **限制：** 连续麻痹同一目标，持续递减；Boss 有韧性点时麻痹只生效一半；仙气的强度和抗性随境界缩放。需要在战旗核心层增加**状态效果**系统。

## 2. 厉苍天：承伤 → 蓄势 → 回击（定，取代早先"技巧+速度反击流"）

核心问题：**"这一击，要不要让我来吃？"** 三杰的战斗问题：任逍遥"怎么破"、傅剑寒"谁站哪"、厉苍天"谁来吃"。

- **主流倾向**：高力量、防御、恢复、体质，技巧中等，**速度是明确短板，后期也是**。玩家可以补速度，但速度不应成为他的最优核心。
- **资源**：内力（传统蓝条，会回，次要）+ **战意**（主角，暂定上限 5 格，后期随剧情到 7~8 格）。普通招用内力，重招看战意。
- **武学类型**：拳术、剑术、心法等，不局限剑系。

### 2.1 战意（暂定）
| 获得方式 | 战意 |
|---|---|
| 自己受到普通攻击 / 重击 | +1 / +2 |
| 成功护卫队友 / 护卫 Boss 重招 | +2 / +3 |
| 防御武学完整挡住攻击 | +1 |
| 每场第一次血量低于 50% / 25% | +1 / +2 |

战意不是第二条蓝条，用来**强化重型武学**：
- **崩山拳**：耗 2 战意，伤害和破势提高；耗 4 战意，大幅提高伤害、击退、无视部分防御。
- **震岳**：耗 3 战意，范围攻击，周围敌人失衡、降低防御，对蓄力中的敌人额外破势。
- **魔闪**（后期剧情解锁）：耗内力 + 战意，提高威力、范围、穿透，让他有少量远程能力。

### 2.2 护卫（核心技能，暂定）
- 选一名队友，持续到厉苍天**下一次行动前**（他速度慢，窗口反而更长）。
- 该队友受到单体攻击、突刺、重击、部分飞射时，厉苍天移动或截击到其身前，改由他承受；成功护卫获得战意。
- **不可护卫**：全屏攻击、地形攻击、精神攻击、世界级规则攻击、明确不可拦截的技能。后期可通过特殊武学强制护卫部分范围攻击。

### 2.3 内力循环（暂定）
内力来自基础自然回复（受恢复属性影响）、受到攻击、成功护卫。循环是：吃攻击 → 回内力 + 得战意 → 打出高消耗重招 → 再承担攻击，而不是站着自动回满。

### 2.4 回血：魔族天赋（与 §4.3 种族规则对齐）
厉苍天是魔族，具有魔族的自动回血。
- 早期未觉醒：**强健体魄**，弱化版，每回合回少量生命，受击后下回合效果提高。
- 魔族大选觉醒：**魔王之体**，回血大幅提高、内力回复提高、重伤后恢复进一步增强、部分伤害可缓慢恢复。
- 公式暂定：`回血 = 恢复 × 专属倍率 × 境界倍率`，早期倍率 0.3~0.5，魔王之体 1.0~1.5，濒死可再增加，具体由模拟器调。
- 同样会被**剑伤**压制（见 §4.3）。

## 3. 傅剑寒：拳术 + 空间换位（定）

- 武学类型：**拳术**。
- 独特机制：**瞬间移动 / 空间交换**。主要走**敏捷路线**。
- 速度和技巧越高：**移动距离越远，消耗越低**，实战中使用次数更多。暂定距离公式 `2 + 速度/10 + 技巧/15` 格，消耗有保底值。
- **每次做出"正确的交换"回复内力。**
  - 正确交换的定义（暂定）：换位后落在敌人**侧面或背后**；或把**即将被攻击的队友换出危险**。
  - 每回合最多返还一次，防止刷内力。

## 4. 与六维的关系

| 属性 | 在这套机制中的作用 |
|---|---|
| 力量 | 普通伤害、剑意倍率之外的基础输出 |
| 速度 | 行动频率、移动距离、傅的换位距离与消耗 |
| 防御 | 减伤（对剑意真实伤害无效） |
| 恢复 | 厉的内力回复、HP 回复、紫气/药物效果 |
| 技巧 | 破招质量、反应点、剑意倍率、傅的换位 |
| 体质 | 气血上限 |

队友全部由玩家加点、是否开放洗点：**待用户确认**（建议允许洗点，收费但不昂贵）。

### 4.1 流派 = 倾向，不是锁定（定）
每个人有主流加点，但玩家可以走偏门：

| 角色 | 主流 | 可行的偏门 |
|---|---|---|
| 任逍遥 | 技巧 | 技巧 + 速度 + 体质（能打能抗） |
| 傅剑寒 | 速度 | 高速度 + 高防御（随时交换）；高速度 + 高力量（刺客） |
| 厉苍天 | 力量 | 补速度改善短板，但不成为最优核心 |

体质主要靠**心法**提供，不靠硬点。

### 4.2 秘籍分类（定）
秘籍分三类：**心法、剑术、拳术**。
- **心法**：负责恢复和体质。**放在技能列表里**，不单独占装备位；**和其他武学一样靠战斗获得熟练度经验**。体质加成随心法熟练度成长，**可超过加点上限 50**（定），不占加点，因此前中期体质不必硬点；具体数值待定。
- **剑术 / 拳术**：攻击类武学，按角色可学类型限制（任逍遥剑术，厉苍天剑术+拳术，傅剑寒拳术）。
- 紫气面板本质是**心法驱动的技能面板**：人族的主动回血都放在这里。

### 4.3 种族与自动回血（定）
| 种族 | 自动回血 | 备注 |
|---|---|---|
| 人族（任逍遥、马友为） | **没有** | 只能主动施放心法、喝药 |
| 魔族 | **每回合 10% 最大血量**（厉苍天另见 §2.4） | 被剑意命中后失效 |
| 精灵 | 会治疗魔法 | 给自己或队友治疗 |

**剑伤（状态）**：被剑意命中后若干回合内，无法自动回血，也无法被药物或治疗恢复（持续 **2 回合**，定）。
- 克制魔族自动回血。
- 马友为是人族，没有自动回血，**靠药**：没做丛林剧情 3 瓶（每瓶 50），做了丛林剧情 1 瓶；被剑意打中后喝药无效，他会震惊"这个小鬼怎么会这样的技能"。药瓶数量只改敌人数据，不改代码。
- **对现有代码的影响**：现有战斗里敌我双方都有 `恢复×2×境界` 的自动回血，需改为只有魔族等有天赋的单位才有；这会让第一章更紧，酒馆战要和次数制一起重调。

## 5. 统一消耗接口（实现约定）

每个武学定义增加：

- `type`：心法 / 剑术 / 拳术，角色只能学兼容类型（心法与攻击武学同在技能列表，各有熟练度）。
- `panel`：`neili` / `ziqi` / `xianqi` / `jianyi`。
- `cost`：`{kind: "charges"|"mp"|"none", amount}`，次数制记录最大次数，内力制记录消耗。
- `effect`：元素或状态（可选）。

单位持有「资源模型」：
- 任逍遥：按面板分组的次数池 + 剑意格。
- 厉苍天：内力池。
- 傅剑寒：内力池 + 换位返还规则。

战斗菜单按面板页签呈现；第一章只显示内力、剑意。

## 7. 已知风险（设计时已标注）

1. 每回合决策层过多：每个机制必须产生新决定。
2. 反击被"资格 / 反应点 / 次数"三道门卡住：建议资格与反应点二选一，保留次数。
3. 单人战斗在网格上深度偏薄：单挑用小棋盘 + 地形机关补空间感。
4. 三个角色三套系统的工作量是三倍（UI、AI、模拟、测试）。
5. 真实伤害和雷麻痹是数值炸点：必须加递减、上限，并用模拟器验证。
6. 第一章酒馆战的旧调参结果作废，加入次数制后需重调。
