# 战旗战斗系统设计（替换现有的单人回合制战斗）+ 世界大地图提纲

> 用户拍板：① 回合按**速度**排队（每个单位依次行动）；② 被攻击时，**速度和技巧够高**就可以临时选一招反制；③ 棋盘 8×6 ~ 10×8 的中小场景；④ 后续要加**世界大地图**：御剑山庄、妖族赌场、魔族四大城市、精灵之森首都等区域。
> 动机：现有战斗里"反制只作用于被选中的一个敌人"，多敌人时其余攻击全额落身（见 numbers 文档 §12）；战旗的站位、朝向、地形、射程天然解决这个问题，并让背刺（潜行）、预判、剑意、三人队伍、天王境界的"发波"都有位置感。参照：《最终幻想战略版》的速度排队与反应技能、《三角战略》的 HD-2D 战棋画面。

## 0. 保留 / 重做
- **保留（数据和公式不动）**：六维、境界与伤害倍率 s、气血公式、武学品阶/熟练度/等级上限、反制判定（✅优势 ⚠勉强 ❌不可行、完美破招）、耐性/晕眩（破势）、剑意（无视防御的不可愈合伤）、预判（揭示接下来 2 次出招）、已识别招式、草药、模拟器 bot 的思路。
- **重做**：战斗核心（棋盘、移动、射程、行动队列、AI、反应）、3D 棋盘舞台、战斗界面、模拟器与 bot、相关测试。
- **原则**：旧战斗保留到新战斗功能对齐后再删；先灰盒（只有格子和方块，纯数据+headless 测试+模拟），验证好玩和数值，再接美术。

## 1. 棋盘
- 方格，尺寸 8×6 ~ 10×8（酒馆战 10×8，森林遭遇 8×6）。每格属性：`height`（0~3）、`terrain`（floor/water/wall/obstacle/bush/furniture）、`walkable`。
- 单位有**朝向**（上下左右）。攻击方位：正面、侧面、背面（以被攻击者朝向算：攻击者在其后方 90° 扇区 = 背面）。
- 高度差：每高 1 级，攻击者 +10% 伤害（上限 +30%）；爬升限制 1 级（任逍遥的"轻功"以后可提高）。
- 障碍与家具：酒馆里翻倒的桌子、长凳是障碍；窄道（门口、桥）使围攻受限——这是站位玩法的核心。
- 数据：`data/maps/<id>.json`：{id, name, width, height, tiles（二维数组，字符编码）, heights, spawns: {player:[…], enemies:[…]}, objective, backdrop（"tavern"|"forest"|"town"，复用现有 3D 场景当背景）, origin（3D 对齐）}。第一批地图：酒馆 `tavern_brawl`（10×8）、森林空地 `forest_clearing`（8×6）、街口 `town_street`（8×6）。

## 2. 回合：速度排队（CT）
- 每个单位有 `ct`（0~100）。每个"刻度"所有人 `ct += speed_ct(speed)`，其中 `speed_ct = 10 + speed`（速度 8 → 18；速度 50 → 60）；`ct >= 100` 的单位行动，同时到达时速度高者先；行动结束 `ct -= 100`（晕眩/休息有不同的扣除）。界面顶部显示接下来 8 个行动者（"行动条"）。
- **首次行动**：玩家方先手突袭（明雷、背后偷袭）时全体玩家方 ct 初始 +60；被发现时敌方 +60。
- 一次行动 = **移动 + 动作** 各一次，顺序任意：
  - 移动：范围 = 3 + floor(速度 / 10)（上限 8），按曼哈顿步数，高度、地形限制，不能穿过敌人。
  - 动作：攻击（选一门武学，射程见 §4）/ 剑意 / 预判 / 试探 / 吃草药 / 待机。
  - 结束时选择朝向。
- **晕眩（破势）**：该单位下一次行动跳过（ct 扣 100），期间防御为 0、受击 ×1.5、不回血；回合数沿用 stun_turns。

## 3. 反制（临时选招）
被攻击时触发"反应"：
1. **资格**（同时满足才弹出反应菜单）：
   - 攻击来自**正面或侧面**（背面攻击不可反制；侧面反制强度 −2）；
   - **技巧资格**：被攻击者至少有一门装备的武学能克制来袭招式类型，且 `反制强度 ≥ 招式威胁 − 5`（沿用现有"差 6 以上不可行"）；
   - **速度资格**：`被攻击者速度 + 该武学先手加成 ≥ 攻击者速度 − 5`（速度差太大来不及反应）；
   - **反应点**：每个单位每个自身回合开始时获得 `1 + floor(技巧 / 15)` 个反应点（技巧 12 → 1，17 → 2，50 → 4），每次反应消耗 1 点。点数用完就只能硬吃。
2. **反应菜单**：暂停动画，列出可用武学：已识别的招式显示判定预览（✅/⚠/❌），未识别显示"？"；可选"不反制"（保留反应点）。玩家选一招 → 沿用现有判定：优势→伤害 0、反击；勉强→伤害减半；完美破招→额外追击、耐性 −2、回复预判点；耐性归零→晕眩。
3. **不满足资格**时：直接承受伤害，飘字"反应不及"/"背后受击"。
4. 范围攻击打中多个单位，每个单位各自反应（各自消耗反应点）。
5. 这意味着：**围攻会被反应点限制，窄道和背靠墙有价值**；而技巧高的人（任逍遥养成后）能连续反制多个来袭者。

## 4. 武学射程与图形
`data/martials.json` 每个武学加 `range`：`{"shape": "melee"|"line"|"ranged"|"cone"|"burst", "min": 1, "max": 1, "width": 1, "pierce": false}`。
- 初始分配（可调）：基础剑术 melee 1；青云剑法 line 2（直线 2 格）；回风剑 cone（前方扇形 3 格）；连环快剑 melee 1（可连击两次）；断势一击 melee 1；流星诀 ranged 2~5；格挡/闪身/太极缠劲是"反制向"武学：攻击射程 melee 1，主要用于反应；绝世剑术 line 3 + pierce。
- **剑意**：射程 line 1~2，pierce，无视防御（沿用）。
- 敌人招式同样有 `range`（马匪乱砍 melee、力劈 melee、探子飞刀 ranged 4、头子开山 line 2 等）。
- 伤害修正：背面 +30%、侧面 +15%、高度 +10%/级；与境界倍率 s、熟练度倍率相乘。

## 5. 预判与已识别
- **预判**（占一次动作）：揭示每个存活敌人接下来 2 次出招的**招名与类型**（沿用 battle.gd 的队列），并在敌人头顶显示预告标记；这些招式被记入 known_moves。
- **已识别招式**：敌人的招式被识别后，反应菜单里显示判定预览。
- **蓄力大招**（Boss 专用）：Boss 的重招在**上一回合先"蓄力"**，棋盘上亮出它的攻击范围格子并显示招名（强制预告），玩家可以走位躲开或准备反制——这是对读招拆招的"看得见"的补充，不依赖预判点数。

## 6. 敌人 AI
- 每个敌人有 `ai`：`rush`（逼近并攻击最近/防御最低的目标）、`archer`（保持 ≥3 格射击）、`guard`（站定，范围内才动）、`boss`（有招式序列与蓄力）。
- 选目标：威胁值 = 对方气血占比低 / 防御低 / 距离近；移动时优先占据高处或背面位置。
- 敌人行动时先移动再攻击；若目标进入反应资格，触发 §3 的反应。

## 7. 胜负与特殊规则
- 目标类型：`defeat_all`、`defeat_leader`（击败头子即胜）、`survive`、`escort`。酒馆战为 `defeat_leader`；战败条件：任逍遥倒下（队伍存在后改为全灭或主角倒下）。
- 逃跑：边缘出口格可撤退（非 Boss 战）。
- 战斗后：经验（熟练度）、掉落（草药/铜钱/残页）、不影响气血外的状态；气血回满（炼体阶段），以后章节再设"休整"。

## 8. 队伍
- 试玩版仅任逍遥；后续傅剑寒、厉苍天等加入后玩家控制所有成员，每人有自己的 loadout（4 栏）与熟练度；队友之间有"协力反制"（以后）。

## 9. 数值影响与调参
- 现有 numbers 文档的六维、s、气血、熟练度全部沿用；新增：移动范围、反应点、背面/侧面/高度修正。
- 第一章旧结论（酒馆战必败/准备好 80%）**作废**，需要在新系统里用模拟器重新调：新增"棋盘 bot"（会移动、占位、选反应）。预期效果：没准备时能靠窄道和走位险胜；准备好后更稳。

## 10. 界面（灰盒阶段用简化版）
- 棋盘 3D：斜角俯视（沿用现有战斗/小镇相机风格），格子高亮：可移动（蓝）、可攻击（红）、当前选中、范围预览。
- 顶部行动条；底部与现在类似的武学卡（动作选择），左下角色卡；点击格子移动/选目标；键盘辅助。
- 反应菜单：被攻击时弹出，列出可选武学卡，附判定预览和反应点数。
- 单位头顶：血条、耐性、已识别招式。

## 13. 待定 / 风险
- 战斗速度：每场战斗要在 5~10 分钟内结束，需要避免行动过长；考虑"快进敌方回合"选项。
- 反应菜单频繁弹出可能打断节奏：反应点限制了次数；提供"自动选最优/总是不反制"的设置。
- 3D 棋盘与现有背景场景的对齐成本（酒馆家具位置 = 障碍位置）；先让地图独立于背景，再逐步对齐。
- 剑意与射程的平衡（剑意 pierce 太强的话要限次数）。
