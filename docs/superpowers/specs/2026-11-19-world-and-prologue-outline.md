# 世界背景与主线前两段（草案，用户口述整理）

状态：「定」为用户已确认；「待补」为用户尚未说明；「建议」为我提出、待用户拍板。

## 1. 世界背景（定）

- 约 100 年前，**和气宗**是天下第一宗派。宗主**东方未来**捡到两个孩子：**东方阳**和**东方云**。
- **东方阳**天生勇者，实力极强，成为人族皇帝；奴役魔人族，妖族和精灵族成为人族附庸。
- **魔族**科技发达，政体类似议会制，靠**魔石**发展科技，实力很强。
- 东方阳推行人族科技改革，发现魔石供应被魔族限制，于是**入侵魔族**。
- 战至一半，**东方云**联合其他种族反击，东方阳帝国覆灭。
- **和气宗被清算**，几位师兄弟逃到荒山地区，建立**紫霞派**：保留和气宗的**心法**，剑法等武学失传，紫霞派从天下第一跌到江湖三流。

## 2. 实力标尺（定）：六维合计

| 极意 | 200~299 | 东方云 260 |

## 3. 人物（定）

- **任逍遥**：流落四方的少年，剑术无师自通，曾住孤儿院，受院长嘱托去紫霞镇拜入紫霞派，崇拜东方阳。序章开始时 9 岁。
- **紫殇**：紫霞派掌门，地灵巅峰，四十多岁，紫霞师姐的父亲。性格像迈特凯：热血、爱激励人、规矩少。口头禅："只要能一直做好事、帮助别人，什么时候都是年轻的。"
- **孙艺**：师娘，人杰巅峰，常吐槽紫殇四十多了还像十八九岁的年轻人。
- **四位师兄**：人杰水平。
- **紫霞师姐**：紫殇的女儿。五年后已嫁给御剑山庄少庄主。
- **三火道长**：京城三火教掌门，年迈，天王级，六维 170。
- **东方凯**：**只在御剑山庄出现，此前任何剧情都没有他**。25 岁，军人，剑术十分高明，是少年英雄大会决赛的对手，同时是序章的**外援**（临时队友，属性约等于做完大量支线的任逍遥）。**东方阳的后代，剧情中不体现，是伏笔**，其故事用户后续补充。
- **厉苍天**：男二，身高 1.9 米，力大无穷，地灵，起初是劫匪。
- **傅剑寒**：下一篇章出场。
- 待补：师姐姓名；四位师兄的姓名、性格、武学风格；东方凯的故事。

## 4. 主线时间线（定）

说明：用户口中的"序章"是整个第一大段，包含下面 A、B、C 三部分，一直到御剑山庄的少年英雄大会。

### 序章 A：9 岁，入派与一个月养成
1. 任逍遥到紫霞镇，打败马匪。
2. 加入紫霞派。师傅说"接下来一个月好好适应一下"，进入自由养成期（四时段制，见 §6）。
3. 一个月养成结束，**剧情跳转三年**。

### 序章 B：12 岁，三火上门
1. 提一下"**法外三月**"：皇帝宣布三个月内兵力不足，无力管江湖，江湖恩怨自行解决。
2. 同时，**东方阳的御神剑术重新出世**，各派争相寻找。此剑术学成后**技巧 +20**，剑招奇怪，速度与技巧大幅加成。
3. 任逍遥奉命去买好茶好吃的；回来被告知"有贵客来访"，来的是三火道长。
4. 京城三火教掌门年迈，三火教即将被六大门派吞并。三火翻古书发现紫霞派，前来拜访。
5. 三火与紫殇交谈，紫殇慷慨地分享紫霞剑术和秘籍；三火认为紫殇在骗他，开始屠杀紫霞派。
6. 三火因年迈，被任逍遥**剑意偷袭**；二人一起从紫霞镇悬崖跌落。三火死，任逍遥没死。
7. 任逍遥偷学秘籍和心法，在山中养伤五年。

### 序章 C：17 岁，地灵（镖局到御剑山庄）
1. 爬出山，发现紫霞派已被三火派残余灭门；紫霞因嫁到御剑山庄少庄主而逃过一劫。
2. 任逍遥决心寻找紫霞，先在镖局当镖师赚钱。
3. 押镖途中遇到劫匪厉苍天，两人交手，任逍遥获胜，保住了镖。
4. 镖局局长赠送**少年英雄大会**邀请函，地点御剑山庄。
5. 擂台单挑：击败御剑山庄少庄主（紫霞的丈夫）；决赛对东方凯，不敌。
6. 紫霞带着紫殇来看他：紫殇从强壮的中年人变成瘦弱老人，经脉俱废；紫霞从少女变成因操持家务而憔悴的人。任逍遥虽输，却完成了自己的目标（见到他们）。

## 5. 与机制的对应（建议）

| 剧情 | 对应机制 |
|---|---|
| 紫霞派保留心法、剑法失传 | 心法是紫霞派的底子，体质靠心法；任逍遥要向外收集剑术与拳术秘籍 |
| 紫霞派落魄 | 资源紧缺、次数制 |
| 三火天王 170，任逍遥炼体 | 现有境界压制规则：低境界打高境界伤害落到 1，破局只能靠剑意（无视防御）和读招；三火战天然是"以巧破力"的第一次示范 |
| 序章一个月自由期 | 与紫霞派最后的平静日子，养成与关系建立的核心；**建议：这一个月选择的修炼方向，继承到三年后和五年后的起点，不因灭门而白练** |
| 御神剑术 技巧 +20 | 传说级武学与属性加成，是后期数值上限的锚点 |
| 东方凯外援 | 御剑山庄阶段的队友；同时是英雄大会决赛的对手，伏笔：东方阳后裔 |
| 魔族议会、魔石 | 魔族敌人用术法与魔石器械，对应后期"破术" |
| 东方阳 | 终局 Boss；任逍遥崇拜他，而紫霞派是被他间接毁灭的和气宗后裔，是长线反转点 |

## 6. 时间制（定）

- 一天四个阶段：早上 / 白天 / 晚上 / 深夜；剧情节点带截止日期，明确显示剩余天数。
- 自由走动不耗时；**任务交付时扣时间**，接任务时显示预计耗时。
- 入派后的一个月使用时间制；之后三年是剧情跳转。序章 C 是否也用时间制，见 §8。
- 外援（东方凯）只在序章出现，且只在御剑山庄阶段，属性约等于做完大量支线的任逍遥，作为安全网和全局数值标尺。

## 7. 两场"结果固定"的剧情战斗（建议）

- 三火道长：天王级，不可能正面打赢。做成可玩战斗：玩家靠破招保命、积攒剑意，达成"剑意偷袭"的结局条件，一起坠崖作为过场。
- 东方凯（第一章）：任逍遥注定落败。做成可玩的擂台，结果固定为败，表现好坏影响奖励和后续对话，不用"打到死为止"。

## 9. 序章 C 详细：御剑山庄篇（用户口述，后半段尚未讲完）

### 9.1 设定与人物
- 时代较封建：带着残废的父亲住进御剑山庄这样的大家庭，本身就招人嫌，山庄的人普遍讨厌紫霞一家。
- **山庄大祖母**：封建家主，对紫霞一家十分残忍。
- **段正天**：御剑山庄庄主；**段暄**：紫霞的丈夫（少庄主）。两人对紫霞一家很好，但无法违背大祖母。
- **副掌门**及其儿子（23~24 岁，成年）：反派。
- 实力：正常养成的任逍遥约 100~130，全做完可到 140；山庄里除了三火（已死）、庄主段正天、东方凯之外，没人能单挑赢他，一对多也没希望。

### 9.2 剧情节拍
1. 任逍遥与紫殇重逢，两人都很开心（紫殇已残废）。
2. 任逍遥在山庄多次击败众人；约半个月里偷学了山庄剑术，并发明了克制它的剑术，山庄对紫霞一家更加厌恶。紫霞为讨好大祖母，不断干活。
3. **日常节奏**：白天挑事、做任务、养成（全做完可到 140）；**晚上照顾紫殇，与他聊武学**，鼓励他恢复紫霞派，一次次对话逐渐点燃紫殇复仇、重振紫霞派之心。
4. 副掌门的儿子（23~24 岁，成年）强抢民女，被任逍遥发现并击败，施以重创（具体表现方式待定，见 §9.4）。
5. 民女一家请任逍遥喝酒，他赴约。紫殇在卧室等他，等来的却是副掌门，带人打伤紫殇，怒骂他废物。
6. 任逍遥回来发现紫殇重伤，愤怒之下杀了副掌门和他的儿子，**其余人没碰**（底线：只杀直接行凶者，不滥杀），随后被段正天击败，关了起来。
7. 紫霞去求情，被大祖母打伤："你们紫霞派一家子垃圾，本身就是高攀，还不知收敛。"
8. 紫霞把怒火发泄到紫殇身上：如果你不一直灌输大侠梦，逍遥怎么会老行侠仗义；我们是平凡的人，没有东方兄弟的天赋，照顾好小家庭就已经很努力了。紫殇的眼神沉沦。
9. 一个月后是御剑山庄**百年庄庆**。段正天决定先不杀任逍遥，庄庆照常举行。
10. 紫殇在屋里看着紫霞秘籍，很难过，认为自己害了任逍遥，开始发疯；忽然发现**紫霞秘籍逆练就是御神剑术**，立即修炼，恢复实力，突破到**天王**，开始复仇。
11. **百年庄庆当天**：紫殇一反平日的不修边幅，精心打扮：头发扎成背头，一身紫衣，眼睛里是妖媚的紫气；载歌载舞、喝得很多，与以前瘦弱的样子判若两人。紫霞察觉父亲不对：平常被人瞧不起会难过，这次完全没有。
12. 段正天示意他入座；大祖母不悦，令侍卫把他扔出去，四个人杰侍卫连他的衣角都摸不到。紫殇说要给段正天送贺礼：**御神剑术**，全场震惊，紫霞劝阻。
13. 大长老出手威胁（"胡言乱语就打死你"），被秒杀。紫殇："你们想要的御神剑术在这里。"天王的段正天仅十余招被击败，全场大乱。
14. 众人胃痛——紫殇在食物里下了毒，只有段暄和紫霞没事。几位长老联手，也被击败。
15. 紫殇胸口不顺，是**紫气堵塞**，他不在乎。他一步一步走向大祖母，大祖母喊"你这个废物要干什么"，被他打断手脚，杀死。
16. 紫殇释放内力（天王级），击晕紫霞——他要把紫气传给紫霞，因为知道她以前也是行侠仗义的女侠——然后飞出大堂。
17. **厉苍天**想趁百年庄庆溜进山庄偷东西，发现一片混乱，遇到段暄；段暄请他帮忙救任逍遥。厉苍天本想走，但发现被下毒的人都站了起来，被紫殇的紫气控制。他掩护段暄，一起去**家法堂**救出任逍遥。
18. 任逍遥很自责（确实是自己一直挑事），得知紫殇的事，准备阻止他。
19. 出狱后，任逍遥发现**东方凯**正被紫殇的紫气所控制的人袭击，出手相助。两人一起理清了经过。
20. 东方凯判断：凭大家无法击败天王；但可以把紫殇**引导到铸剑后山，打碎熔炉，用泰坦之血烧死紫殇**。
21. 任逍遥决定**先谈谈**，实在不行才这么做。**紫殇注定会死。**
22. 段暄去点燃熔炉，把凝固的泰坦之血融化。任逍遥、厉苍天、东方凯三人前去寻找紫殇。
23. 队伍实力：厉苍天 125；任逍遥约 130（不做大量支线），全做约 150；东方凯 155——他不是天王，只是境界未到，东方家的勇者之血为他加了 5 点力量和体质。
24. **紫殇两阶段**：
    - 第一阶段：虽是天王，但身体残废，**身体仍是地灵**，可以被打伤，血量约 1000。
    - 被击败后，被紫气吞噬，变成怪物，彻底成为天王，**失去意识**，血量 1800，**受到的伤害都是 1**。这一步之后转入熔炉计划。

### 9.3 对设计的影响（建议）
- **四时段制正好用在这里**：白天挑事、做任务、养成；晚上陪紫殇聊武学，累积一条"紫殇复仇之心"的关系进度，是剧情推进的计量，不只是养成。
- **体验是"强者"**：任逍遥单挑无人能敌，一对多也强，战斗应该表现"以一敌多"（破招、反击连锁），和三火战的"以弱胜强"形成对照。
- **三场结果固定的战斗**：三火（靠剑意偷袭取胜）、东方凯（落败）、段正天（落败、被囚）；其余多数战斗是任逍遥占优，用来体现成长。
- **逆练 = 御神剑术**：三火当年怀疑紫殇隐瞒，其实秘籍里确有，只是要逆练；这是个很强的反讽。
- **紫殇成为天王级 NPC**，可能成为后续剧情的强力角色，需要在数值标尺上预留位置。
- **紫殇战是第一场"真正的 Boss 战"候选**，正好用上新战斗系统：御神剑术"剑招奇怪、速度技巧大幅加成"，适合做形态混搭、不可破招式与蓄力预告；被毒控制的人是带紫气的杂兵（无弱点、无韧性）；**紫气堵塞**可做成弱点或计时器；紫殇的紫色与任逍遥自己的紫气面板呼应。
- **数值**：段正天（天王）被十余招击败，紫殇应明显高于段正天；任逍遥满养成 140，加厉苍天协助。紫殇的数值待定。
- **厉苍天在这里第一次站到任逍遥这一边**，可能是他入队的契机；东方凯作为外援的戏份仍待补。
- 紫殇与任逍遥师徒相残的情感冲击，是整段的高潮。
- **外援东方凯就位**：数值 155 约等于全做支线的任逍遥 150，印证了"外援 ≈ 全支线任逍遥"这把标尺。
- **铸剑后山战是"地形与时机战"，不是硬打**：三人都是地灵（境界压制系数低），紫殇是天王，正面打不过。关键是把紫殇引到熔炉区域、打碎熔炉、泰坦之血灼烧。需要新能力：战场目标（引导区域、可破坏物）、段暄点燃熔炉的回合倒计时、泰坦之血造成的危险地格。
- **紫殇战两阶段**：第一阶段是正常战斗（天王技、地灵体，血量约 1000，可被打伤）；击败后被紫气吞噬变成怪物，进入第二阶段（天王体，血量 1800，伤害锁定为 1，失去意识），此时不能再靠打，而是执行熔炉计划。"先谈谈"可作为第一阶段中的对话插入，由玩家表现决定紫殇有没有清醒、有没有遗言。（建议，待确认）
- **需要的新能力**：①单位"攻击境界"与"防御境界"分开（紫殇一阶段攻击按天王、防御按地灵）；②敌人"阶段"（血量归零时转入下一阶段，换血量、招式、AI 与伤害规则，不算战斗结束）；③第二阶段的"伤害锁定为 1"，建议连剑意的真实伤害一起锁定；④第二阶段怪物 AI 要有可预测的规则（比如优先追击最近或仇恨最高的目标），否则"引导"没法设计成谜题；⑤泰坦之血的灼烧伤害不受"锁定为 1"限制，建议按最大气血百分比每回合结算。
- **数值待统一**：前面说山庄篇全做约 140，这里说全做约 150，需要确认是不是此后又成长了一段。
