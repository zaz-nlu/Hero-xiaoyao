# 紫霞林 · 养成教程区 设计（试玩版第一章）

用户原话要点：地图要扩充；加角色属性；加支线任务，可以获得属性；从紫霞镇边缘出去是荒山区域，紫霞镇旁边是森林，可以探索；能提前看到马匪，但要隐藏自己；沿着马匪走的路能找到宝箱，里面是一把"普通的剑"（速度+1 力量+1）；这块是**养成教程**，主角直接去酒馆打马匪和"马匪头子"会很吃力；**不要让别人知道马友为的名字，他就是"马匪头子"**。

下面是我（Claude）替用户定的方案，数值和细节都可以改。

## 1. 流程（试玩版第一章）

1. 开局在紫霞镇。酒馆门口站着马匪头子和两个马匪（和现在一样，可交谈、可战斗）。
2. 玩家**可以直接硬打**：此时属性是初始值，战斗设计得"很吃力"（见 §6）。
3. 也可以先**养成**：
   - 包子摊老板（支线「草药」）：去林子里采 3 株草药 → 恢复 +2。
   - 紫霞弟子（支线「试招」）：和他切磋一场（点到为止的战斗，无伤亡）→ 技巧 +2，并教会"读招"的基础。
   - 紫霞弟子（支线「林中探子」）：林子里有马匪探子，偷袭解决他 → 力量 +1、防御 +1。
   - 林中宝箱（无需任务）：沿马匪巡逻的路走到尽头，打开得到「普通的剑」（装备：速度 +1、力量 +1）。
4. 养成完回酒馆打马匪头子，难度合理。

## 2. 地图

- 紫霞镇南岸（过桥后）的南出口 → **紫霞林**（新场景，约 44×44）。
- 紫霞林的南/东出口 → **荒山**（本版只做入口：提示"前方荒山，暂时过不去"，作为之后章节的占位）。
- 紫霞林内容：树（柳树/灌木/竹/岩石素材）、一条蜿蜒土路、2 处草丛可藏身、2 组马匪巡逻（每组 1~2 人）、1 个宝箱、3 株草药、1 个单独的马匪探子（支线目标）。

## 3. 潜行（"提前看到马匪，但要隐藏自己"）

- 马匪是**明雷**：在地图上可见，沿固定路线巡逻。
- 马匪有视野锥：距离 6.5、夹角 ±40°。玩家蹲伏（按住 Shift）时视距减半、移动速度减半。
- 草丛（藏身点）：玩家在草丛范围内且蹲伏时只在 1.5 距离内会被发现。
- 被发现：马匪头顶出现"！"，0.6 秒后触发战斗（马匪先手，非 first_strike）。
- 偷袭：从背后（马匪朝向的反方向 ±60°）靠近到 1.8 以内按 E → 战斗，玩家 first_strike。

## 4. 属性与成长

- 六维属性（力量、速度、防御、恢复、技巧、机关）不变；新增 `GameState.stat_bonus`（任务/奖励永久加点）与 `equipment`（装备）。
- 战斗时玩家属性 = 基础（player.json）+ 永久加点 + 装备加成。
- 角色面板（按 C）：头像、六维（基础+加成明细）、装备、熟练度；任务面板（按 J）：进行中/已完成任务、目标进度。
- 获得物品/属性时屏幕上方弹提示："获得 普通的剑" "力量 +1"。

## 5. 任务系统

- `data/quests.json`：每个任务 id、名称、发布者 NPC、阶段对话、目标列表（collect 物品 / defeat 敌人 / talk NPC / flag）、奖励（stat 加点 / 物品 / 熟练度经验）。
- NPC 对话按任务状态切换：未接（发布）→ 进行中（提示）→ 可交付（完成对话并发奖励）→ 已完成（普通闲话）。

## 6. 难度（"直接去酒馆会很吃力"）

- 初始属性下打马匪头子的预期：不使用预判/不会读招几乎必败；会读招也只能险胜（本版目标：聪明 bot 胜率 15%~35%，加点+装备后 65%~85%）。
- 马匪战斗同理：初始状态下一个马匪是 2 回合内能解决的，但两个马匪同时上很吃力。
- 数值通过 `tools/simulate.gd` 的模拟验证，调敌人数值而非改玩家初始值。

## 7. 保密：马友为的名字

- 玩家和 NPC 都不知道他叫马友为：游戏内所有显示（说话人、敌人名、交互提示、日志、任务文本）一律叫"**马匪头子**"。
- 内部 id 仍用 `ma_youwei`（代码、文件名不变）；立绘不变。
- 以后剧情揭示身份时，再把显示名改回真名（用一个 flag `ma_name_revealed` 切换，本版不触发）。

## 8. 实现里程碑

1. M1 保密显示名 + 成长核心（物品/装备/加点/任务数据与逻辑、战斗接入）。
2. M2 角色面板/任务面板/提示条。
3. M3 紫霞林场景 + 南出口往返 + 战斗舞台支持森林。
4. M4 潜行马匪 + 宝箱 + 草药采集。
5. M5 任务内容与 NPC 分支对话（草药、试招、林中探子）。
6. M6 数值模拟与调优。
